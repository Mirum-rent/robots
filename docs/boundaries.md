# Границы открытого комплекта

[На главную](../README.md)

Включены новая статическая витрина, новые поясняющие схемы, обезличенные описания проектов, реестр утверждений/источников и оригинальный синтетический Python-демонстратор со своими тестами и отчётами.

Исключены рабочее торговое ядро, торговые алгоритмы и параметры, конфигурации источников, ключи, токены, настоящие счета и внешние request ID, необезличенные логи, истории с суммами, сведения клиентов, внутренние инструкции и исходная история Git. Границы не реализованы обфускацией: закрытая логика вообще не переносилась в комплект.

Наличие исходника — статическое доказательство. Сохранённый тестовый отчёт — историческое доказательство конкретного прогона. Новое исполнение демо — runtime-доказательство только демо. Ни один из этих уровней не доказывает текущую операционную готовность, брокерский допуск или доходность исходных роботов.

Демо не содержит сетевых клиентов. Его API — объект внутри процесса; полезная нагрузка фиксирована как record_sample / SYNTHETIC-SAMPLE. SQLite хранит только синтетические данные во временном каталоге. Браузер читает встроенную запись отчёта, без API-запросов и без Python. Контракт fake с авторитетным чтением отличается от реальных eventually consistent сервисов.

Исходники и полные отчёты реальных проектов закрыты. Публичные SHA256 и имена источников позволяют обозначить точный снимок, но не заменяют доступ к нему и не дают внешнему читателю возможности самостоятельно воспроизвести закрытые прогоны.
